# Правила внесения изменений

## Обязательные команды перед коммитом
- `dotnet build` — сборка проекта
- `dotnet test` — запуск тестов

## Запрещено
- Прямые коммиты в `main`
- Коммитить `.env`, `bin/`, `obj/`, `.vs/`, логи
- Force-push в общие ветки

## Порядок приёмки изменений
1. Создать issue с описанием задачи
2. Создать ветку от `main`: `feature/...`, `fix/...`, `docs/...`
3. Делать атомарные коммиты с понятными сообщениями
4. Push ветки в origin
5. Открыть Pull Request со ссылкой на issue
6. Пройти review
7. Merge в `main`
8. Удалить feature-ветку
