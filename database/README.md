# Миграции PostgreSQL

Схема изменяется скриптами из `database/migrations` в порядке их номеров. Таблица
`schema_migrations` хранит применённые версии. Каждый скрипт и запись о нём
выполняются в одной транзакции. Повторный запуск пропускает применённые версии.

`001_initial.sql` создаёт начальную схему. Он повторяет прежний
`postgresql-schema.sql`, поэтому его можно применить и к существующей базе.
`002_data_rules.sql` запрещает отрицательные остатки и неверные суммы.
`003_low_stock.sql` добавляет порог остатка для списка закупок.
`004_user_roles.sql` ограничивает значения роли пользователя.

Для изменения схемы используйте администратора PostgreSQL с правом `SET ROLE
musicstore_migrator`. Приложение продолжает работать под `musicstore_app` без
права менять таблицы. Перед обновлением действующей базы сделайте резервную
копию и проверьте, что существующие строки соответствуют новым ограничениям.

```bash
export MIGRATION_DATABASE_URL='postgresql://postgres@localhost:5432/musicstore'
make migrate
```

Файл `postgresql-schema.sql` оставлен для истории. Для новых установок
используйте только миграции.
